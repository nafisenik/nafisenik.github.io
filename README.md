# Personal Webpage with al-folio Theme

This repository contains the personal website for **Nafiseh Nikeghbal**, available at [nafisenik.github.io](https://nafisenik.github.io).

## al-folio

The website is powered by [Jekyll](https://jekyllrb.com/) with the [al-folio](https://github.com/alshedivat/al-folio) theme.
