The **GIRT** line of work studies Issue Report Templates (IRTs) in open-source software development.

- **GIRT-Data** is the first and largest dataset of Issue Report Templates collected from GitHub, released with tooling to study and support structured issue reporting {% cite nikeghbal2023girtdata %}.
- **GIRT-Model** builds on this dataset to automatically generate structured IRTs from developer instructions {% cite nikeghbal2024girtmodel %}.

- 💻 Code: [GIRT-Data](https://github.com/kargaranamir/GIRT-Data) · [GIRT-Model](https://github.com/kargaranamir/GIRT-Model)
